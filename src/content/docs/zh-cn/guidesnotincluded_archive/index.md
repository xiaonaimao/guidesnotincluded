## 实用站点

WIKI

[https://oxygennotincluded.wiki.gg/](https://oxygennotincluded.wiki.gg/wiki/Oxygen_Not_Included_Wiki)

Wiki 里有复制人、资源、小动物、喷口、小行星，以及游戏里几乎所有东西的资料。

PROFESSOR OAKSHELL'S LAB

<https://zari.rtk0.net/ProfessorOakshell/index.html>

一堆实用计算器：食物、农耕、热量、火箭等。

TOOLS NOT INCLUDED

[(https://toolsnotincluded.net)](https://toolsnotincluded.net/map-tools/map-browser)

Tools Not Included 可以浏览地图，帮你找到恰好有你要的那类喷口和行星的档。可惜网站停摆了一段时间，但有回归的希望。

ONI ASSISTANT

[https://oni-assistant.com](https://oni-assistant.com/)

Oni Assistant 有很多实用工具，包括食物计算器和（本体的）火箭燃料需求计算器。

Klei 论坛可以看游戏更新、了解 mod、提交建议或 bug 报告等等。

关于

## 关于

大家好，我是 some random Finn（某个随机的芬兰人）。要说我这些年玩《缺氧》花了几千个小时，你可能会想两件事：一是我很懂这游戏（并不），二是我常用的设计早就烂熟于心（并没有）。

社区整理的资源、指南和建筑设计，对我学着为复制人拼凑出一种过得去的生活帮助巨大。我做这个网站就是为了回馈这个美好的社区。官方说法是如此。

实际上，我做这个网站是为了不用每次都花几个小时在油管视频里来回拖进度条找建筑设置和概览图。（不过要是有人问，就说是因为社区。）

隐私政策

## 隐私政策

本站使用（并托管于）一个商业服务（叫 Wix）。因为它好用，而我懒。他们保留在本站放置 Cookie 的权利。（抱歉。本站的目标是零 Cookie，但我得先学会 Wordpress 之类的。问题还是出在那个"懒"字上。）

我没有在本站放置任何 Cookie，也没有授权任何第三方放置 Cookie。我不收集本站访客的数据，不共享、不出售本站访客的数据。

一条通用的隐私建议：借助电子前哨基金会（EFF）的浏览器插件 [Privacy Badger](https://privacybadger.org/)，你可以拦截一部分追踪，并看到哪些网站在试图追踪你。我自己在用，热烈推荐。
