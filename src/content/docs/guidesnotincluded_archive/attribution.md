This is an **unofficial, non-commercial community archive** of
[guidesnotincluded.com](https://web.archive.org/web/2025/https://www.guidesnotincluded.com/),
an *Oxygen Not Included* guides site created by **Some Random Finn**. The
original site is offline; these pages were rebuilt from the
[Internet Archive](https://web.archive.org/) and reformatted from the original
Wix HTML into Markdown.

## Original author

All guide text is the work of **Some Random Finn** (guidesnotincluded.com).
In their own words from the site:

> "Hiya, I'm some random Finn. […] The resources, guides and builds put together
> by the community have been a huge help in learning how to piece together an
> acceptable existence for my dupes. I created this site to give back to that
> wonderful community."

The split is drawn by file, so it's always clear which applies: a guide page
stays CC even when it loads a widget — it just references an MIT code file. A
component that reproduces the author's actual words or data keeps that
reproduced content under CC. Interactive additions still keep each page's
attribution credit and stay non-commercial.
